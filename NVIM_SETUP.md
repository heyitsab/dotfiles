# Neovim Plugin Setup

Your neovim config now includes:

## 🎨 Plugins Added:
- **gruvbox** - Color scheme
- **nvim-tree** - File explorer with icons
- **fzf.vim** - Fuzzy finder with preview
- **nvim-web-devicons** - File icons (Nerd Font)

## 📦 Installation:

**First time:** Just open nvim and plugins will auto-install:
```bash
nvim
```

Wait for the installation to complete, then restart nvim.

## ⌨️ New Keybindings:

| Keys | Action |
|------|--------|
| `,e` | Toggle file tree |
| `,f` | Find files (fuzzy) |
| `,g` | Search content (ripgrep) |
| `,b` | Search open buffers |
| `,w` | Save |
| `,q` | Quit |
| `,h` | Clear search highlight |
| `,-` | Horizontal split |
| `,\` | Vertical split |
| `Ctrl-h/j/k/l` | Navigate splits |

## 🌲 File Tree Usage:
- `Enter` - Open file/folder
- `a` - Create file/folder
- `d` - Delete
- `r` - Rename
- `q` - Close tree
- `?` - Show all commands

## 🔍 FZF Usage:
- Type to search
- `Ctrl-/` - Toggle preview window
- `Enter` - Open file
- `Esc` - Cancel

## 🎨 Font Setup:
**Important:** Set your terminal font to "Hack Nerd Font" or "Hack Nerd Font Mono"
- In Ghostty: Open settings and change font family
- Without Nerd Font, icons will show as boxes

Enjoy your enhanced vim setup!
