# Copilot CLI Instructions

## Git Rules

- When working on a larger change, **ALWAYS** think through how that change can be broken down into individual commits.
- Avoid committing yourself. Leave all changes staged or unstaged so I can review the diffs easily. Only commit if multiple commits are needed to complete a task.
- **NEVER** push to a remote unless I explicitly ask you to do so.
- **NEVER** make any change that will affect a remote or a GitHub resource (pull request, issue, etc) without explicitly asking me first.

## PR Rules
- When generating a PR descriptions, always prioritize describing the need and the general approach.
- Include links to code and documentation where available and appropriate.
- Avoid making file-by-file descriptions of implementation details.
